CREDENTIAL DROP BOX
===================

Use this file to hand Claude a site's login without typing it into the chat.

1. Fill in the lines below for ONE site (leave anything you don't have blank).
2. Save the file, then tell Claude which site it's for, for example:
   "I put the Acme login in the drop box."
3. The studio files the details into that site's private folder and clears this file.

Claude is blocked from opening this file, and the studio's own tool does the filing, reporting
only which lines it found. Details are stored outside this folder, never in git or your GitHub
backup. Tell Claude as soon as you've saved, so the file is cleared right away.

Where to find these: your hosting dashboard's SSH or SFTP page (on Kinsta: Sites → your site →
Info → SFTP/SSH). If the host shows a line like "ssh user@1.2.3.4 -p 12345", you can paste that
whole line instead of the host, port and username lines.

─────────────────────
Site address:
SSH host:
SSH port:
SSH username:
SSH password:
WordPress folder on the server:
Hosting company:
