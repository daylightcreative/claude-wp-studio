# reference/

Durable external pointers and reference material — things you look up, not lessons you
learned. Examples of what belongs here over time:

- Useful documentation URLs (WordPress block editor handbook, `theme.json` reference,
  Gravity Forms docs, host knowledge bases).
- Account/dashboard locations (which host panel, where staging is created) — *locations,
  not credentials*.
- Vendor/plugin reference notes worth keeping.

Same format and rules as the rest of the library — see [CONTRIBUTING](../CONTRIBUTING.md).
Add docs as real needs arise; don't pre-fill.
